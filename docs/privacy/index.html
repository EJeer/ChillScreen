Privacy

Your screen stays private.

The ChillScreen app works locally on your Mac and does not capture, record, transmit, or analyze the contents of your screen.

Last updated 2 September 2026

Data used by the app

  • A one-time location fix is optional. It is used to calculate local sunrise and sunset; the resulting coordinates stay in the app's local preferences.
  • Learning history and model settings remain local.
  • Ambient-light readings, enabled sensors, and calibration remain local.
  • The optional value prompt stores its start date and completion state locally on the Mac.
  • ChillScreen has no account, advertising, cloud synchronization, or in-app analytics.

External links

Choosing €0 does not contact any server. Opening Buy me a coffee, a corporate email link, a release download, or another GitHub link leaves the application and opens the external service. ChillScreen does not receive payment status or email contents.

This website

The project website is hosted by GitHub Pages and uses Cloudflare Web Analytics to measure aggregate visits and page performance. Cloudflare states that Web Analytics does not collect or use visitors' personal data or track individual users across its customers' websites. The interactive browser illustration changes only the illustration and cannot alter your display.

Removing local data

Removing ChillScreen does not automatically remove its local macOS preferences. Learning history and feature-specific defaults can be reset from Advanced Settings before uninstalling the app.
